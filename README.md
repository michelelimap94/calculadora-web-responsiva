# Calculadora Web Responsiva

Aplicação web de calculadora desenvolvida com **HTML, CSS e JavaScript**, com interface responsiva e recursos básicos de interação.

## Sobre o projeto

Este projeto apresenta uma calculadora capaz de realizar operações matemáticas básicas e registrar os resultados das operações realizadas durante a sessão.

## Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🧹 Limpeza dos campos e do histórico
- 📝 Histórico das operações realizadas
- 🌙 Alternância para modo escuro
- 📱 Interface adaptável a diferentes tamanhos de tela
- ⚠️ Validação dos campos e tratamento de divisão por zero

## Tecnologias utilizadas

- **HTML5** — estrutura da aplicação
- **CSS3** — estilização, layout e responsividade
- **JavaScript** — lógica das operações e interações da interface
